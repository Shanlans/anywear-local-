# Anywear 本地实时试衣 Demo

本项目使用 Decart 官方 `@decartai/sdk` 0.2.3，前端获取短期 client token 后，使用 WebRTC / LiveKit 连接 `lucy-vton-latest`。永久密钥仅保存在后端 `.env`。没有图片叠加或模拟生成。

## 在 Mac 上运行

这台 Mac 已安装项目依赖，密钥已配置。双击 `start.command`，保持打开的终端窗口运行，然后用 Chrome 访问 **http://localhost:3000**。如已有服务运行，直接访问即可；不要重复启动。

在其他机器上：安装 Node.js 22+，在此目录运行 `npm install`，把 `.env.example` 复制为 `.env`，填写 `DECART_API_KEY`，然后运行 `npm start`。

关闭服务：在运行窗口按 Control+C。改动 `.env` 后须重启。

## 验证

1. 点击「检查 API」：成功说明后端可签发短期令牌，不代表已生成视频。
2. 选上衣，点击「开启实时试衣」，允许摄像头。该操作会向 Decart 发送摄像头视频和参考图，并按账户规则计费。
3. 右下角显示「原始摄像头」，主竖屏只有收到 Decart 远端视频后才显示 AI 输出。原始视频不会伪装为试衣。
4. 在左侧切换上衣、裤子、鞋子；「参考图已发送」只表示 SDK 接受了请求，实际换装以 AI 输出为准。
5. 上传自己的 JPEG / PNG / WebP（最多 10MB），选对品类再上传；建议白底单件，无人物，至少 512px。
6. 测裤子/鞋子时退后，让腿和脚完整进入中间竖屏范围。鞋类标为实验性，尚无本机真实脚部实测保证。
7. 点击「结束」会断开会话并关闭摄像头。每次最多 300 秒，后端和前端均限制会话时长。可在 `.env` 修改 `MAX_SESSION_SECONDS`。

「仅预览摄像头」不会连接生成接口，只在右下角显示原始预览。

## 商品图与限制

`public/products/*.png` 是此 Demo 原创程序绘制的 768×768 无品牌商品示意图，可用于演示，非真实摄影或销售商品。没有使用第三方商店图片。示意图适合验证颜色/类别切换，无法代表真实面料、印花或品牌细节的还原质量。真实评估请上传自己有权使用的商品照片。

一次发送一个参考图、替换一个品类；不同品类切换不保证保留此前单品。没有实现多件搭配合成、尺码/合身度测量、商品照片自动去人物或额外 LLM 图像识别。上传图片只在当前页面内存中保留，刷新后消失；开启试衣后会发送给 Decart。原视频与 AI 输出可能有生成延迟或视觉偏差。

摄像头先由 canvas 中心裁切成 720×1280 竖屏再发送。横屏摄像头两侧会被裁掉；腿/脚需进入中央区域。输出以 contain 展示，避免遮掉有效画面。

## 密钥与本地安全

`.env` 权限为仅当前用户读取，并由 `.gitignore` 排除；不能分享这个文件。没有任何 `VITE_*` 密钥。后端只监听 127.0.0.1，检查 Host、Origin 和请求标识。短期令牌限制为本机来源、指定模型、60 秒有效期，并设置会话时长上限。令牌过期不等于已经开启的会话结束，详情见官方文档。

不要把此 Demo 直接开放到公网；公网版本需增加用户认证、额度/频率管理和 HTTPS。上传图和视频传至 Decart 后的保留政策由其服务条款决定。

## 故障排查

- 摄像头权限：浏览器地址栏允许摄像头；Mac「系统设置 → 隐私与安全性 → 摄像头」允许浏览器；关闭占用摄像头的软件。
- 密钥失败：检查 `.env`，重启服务；检查账户授权、试用额度和余额。
- 无远端视频：检查 WebRTC 网络、防火墙或 VPN；结束后重试。建议使用最新版 Chrome。
- 端口占用：结束旧服务，或者修改 `.env` 的 `PORT` 并访问对应 localhost 端口。

## 中英文和计费统计

页头切换中文 / English，语言偏好在此浏览器保存。页面底部显示每次开始到结束的时长、生成时长估算、本次/累计/平均估算及历史记录。标准 VTON 按官方 $0.02/生成秒估算；等待摄像头和排队时间不会按完整点击时长收费。SDK 返回生成秒数时优先采用；否则按观察到的生成时长估算。均非官方账单。预览摄像头和检查 API 不计入试衣记录。

没有在公开官方文档中查到金额余额 API。剩余金额默认显示未知；可从 Decart 平台核对余额后手动校准，页面扣减此后本地估算。它不包含其他服务、其他浏览器、充值或平台调整。请用单个试衣页统计，异常中断或多标签页并行使用需到平台对账。记录和手动余额仅存此浏览器 localStorage，不上传 GitHub。新增语言需补齐 src/i18n.js 的字典及动态消息；目前交付中文和英文。
