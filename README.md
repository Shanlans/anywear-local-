## Mac 启动

安装 Node.js 24或更新LTS，首次运行 `npm install`（会构建），复制 `.env.example` 为 `.env`，填写 `DECART_API_KEY`。然后 `npm start` 或双击 `start.command`，保持终端运行，打开 <http://localhost:3000/>。已有本机项目已配置密钥，不要把密钥提交。

改源码后 `npm run build` 并刷新；改后端或.env后重启。开发检查 `npm test`。

## 现场使用

1. 固定并锁定 iPhone，后置摄像头朝向你。允许浏览器和Mac摄像头权限，点击免费预览；选iPhone设备，检查光线及站位。
2. 默认完整取景保留摄像头画幅；可选竖屏中央裁切，裁切会放大人物。预览就是模型输入范围。Mac实测接收1280×720横画幅，手机竖持不等于视频自动竖屏；若人物侧躺，预览中选择顺/逆时针90°，人物直立则不旋转。镜像只影响显示，输入默认不翻转。
3. 选择商品和默认Prompt，点击开始实时试衣。视频和参考图将发送Decart并计费；主窗标签区分免费预览与远端AI。
4. 修改Prompt或选择商品/正反面后，点击应用修改。同一会话发送单图+Prompt，不重新连接。右侧已发送在set回执成功后更新，仍不代表服装还原成功；视觉效果看AI画面。
5. 完整取景会铺开右侧空间；“放大试衣区”进一步扩大画面，退出按钮或Esc返回，结束按钮仍可见。可查看原画或小窗进行对比；看原画/编辑期间会话仍计费。结束会关闭本机视频和连接；连接中取消可能等待SDK返回后完成清理，异常记录须平台核对。
6. 测裤子须腰腿入镜，鞋须双脚入镜。新增黑框绿片太阳镜在“配件”分类，使用Add默认Prompt，脸部清晰入镜后开始或应用；脸部贴合、转头稳定性、镜片与标志均待实测。正反面需手动分别应用，没有自动转身识别或多视角融合，背面/文字/鞋类效果不保证。

解锁iPhone、来电、暂停或系统视频特效可能影响取景。遇停帧，结束后锁定iPhone重新预览。建议关闭系统虚化/追踪等效果；一浏览器同来源只允许一个摄像头实例。

新增球衣在“上衣 → 詹姆斯 湖人23号球衣”，使用用户James.jpg正面原图与可编辑默认Prompt，只请求转移上衣，不复制参考人物、纹身、首饰、护臂或篮球。LAKERS字样、23号与人物保持需实测，不保证文字完全准确。

## 原画＋AI同屏录像

刷新页面，免费预览后开始实时试衣；默认勾选“AI出现后自动录像”，两路画面就绪后自动开始。开始试衣前可以取消勾选，选择会在本浏览器记住；也可手动点击“开始对比录像”。左边为实际送入模型的原画，右边为真实远端AI画面，两边按比例完整显示，包含原画/AI标签和录像计时。可继续切换商品；屏幕切到原画或大图不改变录像内容，显示镜像同步到录制画面。

点击“停止录像”，再点击“下载对比录像”保存到Mac。本地浏览器编码，优先MP4，不支持则WebM；无声音、不申请麦克风，不上传后端或云端，不写日志或GitHub。仅录像时长、结果等脱敏诊断可写入本机日志。停止录像不会结束试衣，活动试衣仍按原会话规则计费。左右是同屏采集，AI处理有延迟，不声称逐帧时间同步。

结束试衣、重连、明显停帧或页面切到后台时，录像自动收尾，已录内容保留下载入口。录像模块内部保护为5分钟或约96MiB编码数据；当前试衣30秒上限先到时结束会话并收尾录像。停止录像本身不会结束试衣。每次完成新录像会替换上一次页面内下载入口，请先下载要保留的视频。刷新/离开时若录像中或尚未点击下载，浏览器会提示；关闭页面、崩溃或断电后无法保证恢复未下载内容。下载由浏览器保存流程决定目录和文件名。

已用不含真人的两路合成视频验证原生MP4生成、解码、左右画面与本机下载；这不是换装质量验收。用户现场可录10秒并检查文件，见TEST-015/016。

## 费用与限制

标准VTON按$0.02/活跃生成秒估算，约$1.20/分钟；非官方账单。SDK时长优先，未确认生成或中断标待核对。点击开始到结束记一条会话，每次应用另记操作和耗时。免费预览、检查API不计试衣次数。每次从点击开始起最多30秒（含连接等待），25秒提醒、30秒自动结束；换衣和重连不续时。后端令牌也限制30秒，旧配置不能调大。标准模式连续生成30秒约$0.60/60 credits，实际以平台结算为准。

详细历史与平均花费折叠展示；实际金额余额接口未查到，手动余额减本页估算，不含其他浏览器/应用/平台变动。费用记录在浏览器本机，不上传Git。

官方指南支持配件，但没有针对本图眼镜的效果保证。配件Prompt请求保留原有衣服；单图会话不能承诺此前AI服装继续保留。只支持单参考图，不保证切换品类保留此前衣服；含模特照片尚未自动提取服装。套装上传为实验入口，没有多件组合、自动姿态识别、3D服装或尺码推荐。
