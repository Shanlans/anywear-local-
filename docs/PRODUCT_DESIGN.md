# Anywear Demo 产品与界面设计

目标是在 Mac 的本地浏览器提供接近 Anywear 插件的实时试衣体验：左侧选择商品，右侧竖屏观看 Decart 返回的视频。当前定位是可验证 API 和交互的 Demo，评价重点是连接与单品替换，不把生成结果当作尺码或合身度结论。

版本基线：0.1，更新日期 2026-10-08，Asia/Singapore。

## 用户需求与范围

| 需求 | 当前设计 | 验收标准 |
| --- | --- | --- |
| Mac 本地运行 | Node 后端与静态网页，单个 localhost URL | 双击启动文件后可访问 |
| 左侧商品区 | 全部、上衣、裤子、鞋类筛选 | 分类切换正确，选中态清晰 |
| 商品预置 | 3 上衣、2 裤子、1 鞋类 | 六张图全部显示、能选中 |
| 自己上传 | 选择品类后上传 JPEG / PNG / WebP | 图片加入卡片，选中并用于会话 |
| 右侧竖屏 | 9:16，输入 720×1280 | 实时画面按竖屏显示 |
| 真正实时换装 | 官方 SDK 接口 | 必须收到 Decart 远端视频并观察换装 |
| 密钥不进入客户端 | 后端 .env 与短期 token | 静态资源和提交中无密钥 |
| 中英文切换 | 页头语言菜单，记住偏好 | 标题、按钮、卡片、状态、提示均切换 |
| 其他语言 | 独立 locale 资源和翻译入口 | 添加完整字典及动态句式后验收；目前只交付中文和英文 |
| 台账 | API、产品设计、开发记录、变更日志 | 每次改动同步更新 |
| GitHub | 用户指定 Shanlans/anywear-local- | 源码、原创图、文档与 CI 可追溯；排除密钥 |

## 产品交互

默认选中雾白 T 恤。切换分类只过滤列表，不自动改变已选单品；点击卡片才改变选择。连接前点击卡片只更新选择；连接后异步发送参考图。快速连续点击采用串行策略，发送完当前请求后再发送最新选择，避免并发请求乱序。

主操作为开启实时试衣。用户先授权摄像头，后端再签发令牌，SDK 连接并发送 initialState。原始摄像头放右下角小窗，主窗仅展示远端生成流。空状态、连接、等待首帧、生成、重连、错误和结束各有状态文案。参考图发送成功的文案明确不代表视觉还原已完成。

仅预览摄像头用于检查入镜，不向 Decart 打开生成会话。检查 API 用于验证令牌签发。结束立即释放摄像头、断开生成连接。每次默认 5 分钟，避免忘记关闭造成持续生成。

## 商品上传设计

先选择上衣、裤子或鞋子品类，再选文件。上传文件名只当作商品名称，不作为 HTML 执行。图片类型及大小由浏览器检查，读取失败会提示。上传图只留在页面内存，刷新后清除；开启试衣才作为参考图发送给 Decart。没有把上传变成永久图库，也没有接入自动去人物和视觉 LLM。

## 风格与外观

界面采用安静的服装编辑页风格。底色是暖灰白，主体文字为深灰绿，鼠尾草绿用于选中边框、状态和主按钮。品牌字使用系统衬线风格，正文使用系统无衬线和苹方中文，不加载第三方字体服务。

| --- | --- | --- |
| 页面底色 | #f6f4ef | 柔和、接近纸面 |
| 主文字 | #292e2a | 保持阅读清晰 |
| 主按钮 | #33432d | 聚焦开始试衣 |
| 选中强调 | 绿色边框与圆形勾选 | 同时表达颜色和形状 |

| 卡片圆角 | 12px | 简洁轻柔 |

预置图均为原创程序绘制的单件商品示意图，白底、无品牌、768×768。可以演示颜色和类别，但不是服装摄影。实际面料、印花、轮廓效果必须用合法真实商品图验证。

## 国际化设计

页头提供中文与 English 菜单，localStorage 保存 anywear-language。切换不会重建视频元素，因此不会因语言切换主动断开会话。文案字典独立在 src/i18n.js，包含商品名、品类、权限和 API 错误、计费提醒、状态和帮助。用户文件名保持原文，模型提示词固定英文，界面语言不影响请求品类。

新增语言需要定义 locale、完整静态字典、动态状态句式、日期/货币规范及布局校验，不能只改语言菜单就声称已支持。当前中文和英文已经进行浏览器切换检查；其他语言尚未翻译。

## 体验与可访问性

商品卡片用 aria-pressed，品类采用 tab 语义，动态提示为 aria-live。焦点有可见轮廓，图片有商品名称，结束按钮根据会话状态启用。语言切换同步 HTML lang 与页面标题。权限引导同时覆盖浏览器和 Mac 系统设置。

## 真实效果验收方式

用 Chrome 打开 localhost，检查 API 后选择上衣并开启实时试衣。对比小窗原画与主窗 AI 输出，观察颜色、轮廓、身体运动和脸部变化。再退后测裤子与鞋子，完整显示腰、腿和脚。每个品类记录商品图、模型、测试时长、成功率及明显偏差，但不把人像照片提交公共仓库。

用户停止后确认摄像头灯关闭，页面回到空状态，平台会话结束。持续计费是否停止以平台记录核实，不只依赖 UI 标签。

## 同页计费统计设计

新增页面下方花费区，与试衣间共用语言切换。五个统计项为本次估算、累计估算、平均每次、已结束次数、剩余金额估算。下方逐次记录开始时间、点击到结束的秒数、生成秒数估算、费用、结果和依据。

点击到结束时长用于产品行为记录，不能直接当作生成收费时长。平均值仅覆盖已结束且确认生成的可估算记录，失败未知费用单独显示。数据保存在浏览器本机，不上传仓库。没有历史时均值和余额显示横线，不假设真实余额为零。

余额区域提供手动校准和清除校准，并链接官方账户；校准时禁止存在本页活动会话，避免重复扣减。官方真实余额未接入。单页使用，跨标签统计、正式账单对账、充值同步和官方余额 API 都不作为已完成能力。
