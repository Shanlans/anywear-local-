# 实时虚拟试衣 Demo 实施计划

版本 0.2 · 2026-10-08 · Asia/Singapore · 用户已批准执行。

## 目标与第一性原理

现场展示真实人物持续运动时的远端实时换装，效果可辨认、切换顺畅、停止可靠。页面与功能数量不能代替真人效果验收。代码完成、接口通过、视觉效果通过分别记录。

## 体验方案

桌面左右双栏，左约 360px 为商品、参考面和 Prompt，右为大试衣窗；左独立滚动，1280×800 下主画面及操作常驻。小窗允许页面滚动，移动端画面在上。暖白、深灰、绿色强调，中英文完整覆盖，不翻译用户输入。

当前六件真实商品、七张图片（用户追加太阳镜，见REQ-010/DEC-013）；默认蓝色 T 恤，黑色上衣含正反面。删除示意素材和回退。进入页面预加载参考图，缺图明确提示并禁止发送，提供大图查看与次要上传。原图保留本机，不进入公共仓库。

流程：选择摄像头→免费预览→选衣→开始→观察运动→修改/切换并应用→结束。编辑和选图仅更新草稿，按商品/视角保留当前页面草稿。右侧显示已发送商品，发送成功不代表视觉换装通过。自定义 Prompt 关闭扩写，完整单图与 Prompt 原子 set，同会话切换。原画/AI 查看及小窗不更改连接，显示计费提醒。结束始终可用。

## 摄像头和会话

只申请视频，授权后列设备，优先恢复用户选择，再识别 iPhone，再默认设备。免费预览中切设备，运行中结束再切。用户反馈后默认完整取景，保留源画幅；可选720×1280中央裁切不拉伸，预览与模型实际输入一致。SDK 配置帧率，记录实际设备参数。输入不镜像、SDK mirror=false；显示镜像可切换且原画/AI一致。

摄像头、连接、发送、画面分别管理。授权30秒提示但不自动付费；连接开始60秒无首帧清理；可见页面5秒无新帧警告、15秒结束；重连30秒未恢复结束。SDK自带重连不叠加重连机制。结束连接中请求标记取消，迟到连接立即断开，清理前不允许新连接。5分钟上限，提前提醒。页面离开清理，中断账目待核对。同来源只允许一个活动实例。

iPhone 暂停/解锁/来电可能不触发 ended，检查 track 状态和新帧。固定支架、光线和稳定连接写入使用指引。图像处理、自动服装提取、多图融合、自动切面、尺码测量均不作为已完成能力。

## 质量与计费

先真实原图；若模特干扰先试非生成裁切，另存衍生图，失败登记服装提取后续任务。文字、背面开口和鞋单独评价。一次开始到结束一条会话，每次应用一条操作，记录耗时/结果。标准模式$0.02/生成秒估算，SDK时长优先，未知标待核对。账户余额仍手动估算。模型别名真实版本未知时如实记录。

## 验收

至少一上衣一下装各30秒，检查对应颜色轮廓、身体跟随、人物保持、画面稳定并由用户确认适合展示；正常网络三次启动结束和三次切换不刷新。首帧15秒/换装5秒为优化目标而非能力承诺。记录首帧、请求回执、人工视觉变化、FPS及卡顿，不把模拟验证记真人通过。

优先输入质量和延迟诊断；稳定后再持久图库/最佳Prompt/更多语言；有需要再快速模式/套装/经授权录像。用户现场控制开始结束，没有预设未确认测试预算。
