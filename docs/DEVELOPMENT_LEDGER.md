## 使用与维护

双击 start.command 保持终端运行，访问 localhost。修改源码后重新构建并刷新；改 .env 后重启后端。README.md 给出常规 Node 安装和启动方式。台账不自动定时刷新，后续在此项目进行开发时根据 AGENTS.md 更新；没有创建后台计划或监控。

每次改动记录需求、文件、验证与未解决问题，再提交代码和文档。价格、别名和新增品类需重新核对官方来源。禁止提交摄像头图像、用户商品图、API Key、短期令牌和浏览器账目。

## 下一轮真人验收

1. 在 Chrome 打开页面，点击检查 API。
2. 允许摄像头，选择 T 恤，开启实时试衣。确认主窗是远端 AI，小窗是原始视频。
3. 选择卫衣、裤子、鞋子并点击应用，保持目标部位入镜，记录视觉偏差。
4. 查看 SDK 生成秒数与费用估算，结束后确认摄像头关闭。
5. 在 Decart 平台核对生成时长、费用和实际余额，再手动校准。

未解决：真人首帧/延迟/运动稳定性、鞋类效果、异常断线后费用最终一致性、官方金额余额自动同步。它们不阻碍本地项目启动，但阻碍把 Demo 宣称为已通过完整换装效果验收。
